## 구현할 기능들

1. 경주할 자동차 이름을 문자열로 받아 _쉼표로 구분_ 후 배열에 저장한다.

2. 시도할 횟수를 입력받는다.
3. 자동차 이름, 전진한 거리 2개의 변수를 Car 클래스를 만들고, 생성자를 통해 값을 초기화 시킨다.
4. Car 클래스 내부에 전진하는 메서드를 만든다( 0~9사이 무작위 값이 _4이상_ 인 경우만 전진 )
5. Car 클래스 내부에 전진한 횟수를 출력하는 메서드를 만든다. (이름과 '-'로 출력)
6. 최종 우승자를 출력하는 메서드를 만든다.

## 사용자가 잘못된 값을 입력하는 경우

#### 자동차 이름을 입력받을 때

1. 빈 문자열을 입력하는 경우 <br> -> ""

2. 이름이 5자를 초과하는 경우 <br> -> "_yeonjun_,pobi,woowa"
3. 쉼표의 쓰임이 올바르지 않은경우<br> -> "pobi,,woowa" | ",pobi,woowa" | "pobi,woowa,"
4. 2개 이상의 자동차가 같은 이름을 사용하는 경우<br> -> "pobi,pobi"

#### 시도할 횟수를 입력받을 때

1. 양의 정수가 아닌 음수를 입력하는 경우 <br> -> "-1"

2. 숫자 이외의 값을 입력하는 경우 <br> -> "a" , "@"

## 기타 조건

1. 자동차 이름에 있는 모든 공백은 제거된다.<br>

2. 자동차 이름 입력값 검증은 모든 공백을 제거한 후에 실시한다.<br>
3. 시도 횟수 0번도 올바른 자동차 경주로 인정한다.
