# TDD로 자동차 경주 구현하기

## 서비스 한 줄 요약

자동차가 전진하고, 가장 멀리간 자동차가 우승한다.

## 이번 TDD에서 목표

1.  기능 목록 작성 후 테스트 시나리오 작성
2.  객체의 구체적인 기능은 깊게 생각하지 말고, 간단하게 객체 도식화 해보기
3.  도식화 이후에 어떤 기능부터 구현해볼지 순서 정해보기
4.  하나의 기능을 구현할 때 최대한 리팩토링 하고 다음 기능 넘어가기

## 기능 목록

### 1. [자동차 이름 입력] 경주할 자동차 이름을 입력받는 기능

- [예외] 빈 값이 입력된 경우 (" ")
- [예외] 빈 닉네임이 포함된 경우 (",,pobi")
- [예외] 이름이 5글자를 초과하는 경우 (",pobidd,pobi")
- [예외] 이름이 중복되는 경우 ("pobi,pobi,abc")
- 예외 발생 시 해당 지점부터 다시 입력받는다.

### 2. [시도 횟수 입력] 전진 시도 횟수를 입력받는 기능

- [예외] 빈 값이 입력된 경우 (" ")
- [예외] 숫자가 아닌 경우 ("a");
- [예외] 양의 정수가 아닌 경우 ("0","-1") <- 경계값 테스트 인지
- 예외 발생 시 해당 지점부터 다시 입력받는다.

### 3. [자동차] 1칸 전진하는 기능

- 0~9사이 숫자를 뽑아 4 이상이면 1칸 전진한다.

### 4. [자동차] 1칸 전진 후 자신이 이동한 거리를 출력하는 기능

### 5. [레이싱 게임] 최종 우승자를 결정하고, 출력하는 기능

### 입출력 예시

경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?

```
실행 결과
pobi : -
woni :
jun : -

pobi : --

pobi : ---

pobi : ----

pobi : -----

최종 우승자 : pobi, jun
```

## ✏️ 테스트 시나리오

[지동차]

- [] 자동차 이름이 5글자를 초과하면 예외가 발생한다.
- [] 자동차 이름이 1글자 미만이면 예외가 발생한다.
- [] 뽑은 숫자가 4일때 1칸 전진해야 한다.
- [] 뽑은 숫자가 3일때 전진하지 않아야 한다.
- [] 전진 후, 자신의 이동거리 만큼 '-'(하이픈)을 반환해야 한다.

[자동차들]

- [] 5개의 이름을 받아, 5개의 자동차를 생성해야 한다.
- [] 중복 이름이 존재하면, 예외가 발생한다.

[등수 계산]

- [] 5대의 자동차 중, 가장 멀리 이동한 자동차의 거리를 반환해야 한다.
- [] 5대의 자동차 중, 특정 거리만큼 이동한 자동차를 모두 반환해야 한다.

[레이싱 게임]

- [] 시도횟수만큼 모든 5대의 자동차가 전진시도를 해야한다.
- [] 시도 횟수가 빈 값이라면, 예외가 발생한다.
- [] 시도횟수가 숫자가 아니라면, 예외가 발생한다.
- [] 시도횟수가 양의 정수가 아니라면, 예외가 발생한다.
